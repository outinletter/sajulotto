번들 ID: `com.addvalue.sajulotto`, 개발 팀: `A7QB8PT33N`. 자동 서명을 사용합니다.

`Web/`은 루트 HTML과 로컬 vendor 파일의 앱 번들 사본입니다. 웹 화면 변경 시 함께 갱신하세요. 외부 API와 네트워크 연결 없이 기기에서 계산합니다. 저장한 번호만 UserDefaults에 보관하고 네이티브 공유 기능을 제공합니다.
